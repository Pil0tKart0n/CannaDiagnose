===============================================================================

WAS IST DAS PROJEKT?
--------------------
Eine Expo/React Native App zur KI-gestützten Diagnose von Cannabis-
Pflanzenproblemen. Der User fotografiert seine Pflanze, beantwortet einen
kurzen Fragebogen, und bekommt eine Diagnose mit Aktionsplan.

Tech-Stack: Expo Router + React Native + Claude API (Sonnet 4.6) + TypeScript
App läuft auf iOS/Android via Expo Go.


WAS FUNKTIONIERT BEREITS?
-------------------------
- Foto aufnehmen oder aus Galerie wählen (bis zu 3 Bilder, Mehrfachauswahl)
- Fragebogen: Pflanzenalter, Substrat, Dünger, Licht, Symptome, Änderungen
- KI-Analyse mit 5-Dimensionen-System (Farbe, Textur, Muster, Position, Ausmaß)
- Ergebnis: Diagnose, Konfidenz, Ursachenanalyse, Aktionsplan, Präventionstipps
- Verfeinerung: pH/EC/Dünger nachträglich eingeben → Diagnose wird korrigiert
- Farbkorrektur: User kann Blattfarbe manuell angeben (offline, ohne API-Kosten)
- Pflanzenverwaltung: Profile anlegen, Diagnosen zuordnen
- Follow-up: Erinnerungen nach X Tagen für Nachkontrolle
- Historie: Alle Diagnosen gespeichert und durchsuchbar
- Bibliothek: 100+ Einträge zu Mängeln, Schädlingen, Krankheiten
- PDF-Export und Teilen
- 40+ Dünger-Datenbank mit EC-Bereichen pro Wachstumsphase


WAS WURDE HEUTE (15.03.) GEMACHT?
----------------------------------
1. KORREKTUR-MATRIX (constants/prompts.ts)
   - 30+ lokale Regeln für Diagnose-Korrektur bei Verfeinerung
   - Für jede Kombination aus Erstdiagnose × EC-Zustand × pH-Zustand
   - Beispiel: Mg-Mangel + niedriger EC + guter pH → korrigiere zu N-Mangel
   - Funktionen: detectDiagnosisType(), getECState(), getPHState(),
     getCorrectionHint(), evaluateEC()

2. REFINE-PROMPT ÜBERARBEITET (constants/prompts.ts)
   - KI muss lokale Bewertungen WÖRTLICH übernehmen
   - Darf pH/EC nicht uminterpretieren oder relativieren
   - Bei optimalem pH wird pH gar nicht mehr als Thema erwähnt

3. LOCKOUT POST-PROCESSING FILTER (services/claude.ts)
   - Wenn pH optimal ist, werden negative pH-Aussagen aus der Antwort gefiltert
   - Fängt: "Lockout", "einschränken", "grenzwertig", "zu niedrig" etc.
   - Filtert aus: primaryDiagnosis, rootCauseAnalysis, contributingFactors

4. KOMMA-FIX (constants/prompts.ts + services/claude.ts)
   - WICHTIGER BUG: parseFloat("5,9") = 5 (nicht 5.9!)
   - Deutsches Komma wird jetzt überall in Punkt konvertiert
   - parseNum() Hilfsfunktion statt parseFloat für User-Eingaben
   - pH/EC-Werte werden im Prompt-Text normalisiert

5. BILDOPTIMIERUNG (services/claude.ts + app/camera.tsx)
   - Bilder werden auf max 1568px resized vor Upload (Claude API Limit)
   - Spart 80-90% Upload-Daten bei null Qualitätsverlust
   - Ladezeit von 45-70s auf ~10-20s reduziert
   - Galerie ohne Crop-Editor (sofort statt 5s)
   - Mehrfachauswahl in Galerie möglich
   - expo-image-manipulator installiert

6. DÜNGER IM FRAGEBOGEN (constants/questions.ts + components/QuestionCard.tsx)
   - Neue Frage "Welchen Dünger verwendest du?"
   - Neuer QuestionType 'searchable-select' mit Suchfeld
   - 40+ Dünger durchsuchbar
   - Erstdiagnose bekommt jetzt Dünger-Kontext mit

7. PFLANZE HINZUFÜGEN VEREINFACHT (app/add-plant.tsx)
   - Ein Feld "Sorte / Name" statt zwei verwirrende Felder
   - Optionaler "+ Weitere Infos" Button für Zusatznotizen


BEKANNTE PROBLEME / OFFENE PUNKTE
-----------------------------------
- Die KI neigt dazu, pH-Werte im optimalen Bereich trotzdem als
  problematisch darzustellen. Der Post-Processing-Filter fängt das ab,
  aber ideal wäre es wenn die KI es von Anfang an richtig macht.

- Offline-Modus: Wurde diskutiert, aber ohne KI-Foto-Analyse wäre die
  Qualität nur ~80-85%. Entscheidung: bleibt erstmal online-only.

- TypeScript-Config hat bestehende Fehler (jsx nicht gesetzt,
  module-Einstellung). App funktioniert trotzdem via Expo/Metro.
